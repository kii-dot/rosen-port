# Mutable Components

Mutable components are the core of totoma. It is the building blocks for users to build their personal website. It uses a chessboard and bento concept.

Imagine the page is a piece of chessboard, filled with squares. Uses are able to create bento cubes on top of the chessboard. The cube are pieces that makes up their site.
